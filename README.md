Next Greater Element II em C

Este projeto resolve o problema “Next Greater Element II” utilizando busca sequencial em um vetor circular.

A solução percorre o vetor procurando o próximo elemento maior para cada posição. Caso não encontre à direita, a busca continua do início do vetor até a posição atual, simulando a circularidade do array.

A implementação foi feita sem uso de pilha, utilizando uma abordagem mais robusta e intuitiva, porém com maior custo computacional (O(n²)).

Apesar de existir uma solução mais otimizada utilizando pilha monotônica (O(n)), esta versão prioriza clareza lógica e compreensão do problema.
